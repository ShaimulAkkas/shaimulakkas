The Challenge

Gausul Azam Maizbhandari Polytechnic Institute operated across five separate buildings with no unified network infrastructure. Each building ran independently with ad-hoc connectivity, leading to IP conflicts, no centralized monitoring, and frequent downtime affecting 700+ devices including computers, IP phones, CCTV cameras, printers, and IoT equipment.

My Approach

I conducted a full site survey across all five buildings, mapped every access point, and designed a scalable network architecture from scratch. The implementation was done floor-by-floor to minimize disruption to daily classes.

01

Survey & Planning

Mapped all 5 buildings, identified 700+ device endpoints, designed VLAN scheme and IP allocation strategy.

02

Cabling & Infrastructure

Installed Cat6A and OS2 fiber backbone, patched all endpoints, set up distribution racks in each building.

03

Configuration & VLANs

Configured MikroTik routers, set up 5+ VLANs (Office, Lab, College, Schools, Hostel), enabled DHCP, NAT, and VPN.

04

Monitoring & Launch

Deployed PRTG for real-time monitoring, configured alerts, tested failover, and went live building by building.

Results

The campus now operates on a unified, scalable network with 99.8% uptime. IP conflicts are eliminated through proper VLAN segmentation and DHCP reservations. The IT team can monitor all 700+ devices from a single PRTG dashboard, reducing troubleshooting time by 40%. The infrastructure is ready for future expansion with fiber backbone capacity.

Configuration Snippet

MikroTik VLAN configuration for building segmentation:

mikrotik-vlan-config.rsc 
# Create VLAN interfaces
/interface vlan add name=vlan10-office vlan-id=10 interface=ether1
/interface vlan add name=vlan20-lab vlan-id=20 interface=ether1
/interface vlan add name=vlan30-college vlan-id=30 interface=ether1
/interface vlan add name=vlan40-schools vlan-id=40 interface=ether1
/interface vlan add name=vlan50-hostel vlan-id=50 interface=ether1

# DHCP Networks
/ip dhcp-server network add address=10.10.10.0/24 gateway=10.10.10.1 dns-server=8.8.8.8
/ip dhcp-server network add address=10.10.20.0/24 gateway=10.10.20.1 dns-server=8.8.8.8

# Firewall Rules
/ip firewall filter add chain=forward src-address=10.10.10.0/24 action=accept
/ip firewall filter add chain=forward src-address=10.10.20.0/24 action=accept
