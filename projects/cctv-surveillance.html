Campus-Wide CCTV Surveillance Infrastructure Setup

Gausul Azam Maizbhandari Polytechnic Institute

Overview

Planned and deployed a campus-wide CCTV surveillance system covering computer labs, classrooms, and administrative areas. The setup includes HD IP cameras, centralized NVR storage, motion detection, and a dedicated monitoring station.

Key Highlights

  • Planned strategic camera placement and mounted HD IP surveillance cameras across computer labs, classrooms, and administrative areas.
  • Installed and configured centralized NVR units, storage hard drives, motion-detection triggers, and continuous recording schedules.
  • Managed Ethernet cable routing, connector termination, and configured centralized monitoring screens.

Technology Stack

HD IP Cameras NVR/DVR Motion Detection Ethernet Cabling Connector Termination Centralized Monitoring
