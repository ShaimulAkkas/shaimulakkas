The Challenge

The polytechnic's computer lab needed a complete overhaul. Outdated workstations, unreliable network connectivity, and frequent hardware failures were causing regular session delays for students. There was no standardized imaging, no preventive maintenance schedule, and the LAN infrastructure was unstable — affecting daily practical classes.

My Approach

I managed the end-to-end deployment from hardware assembly to network setup, ensuring every workstation was ready for daily use with zero downtime during practical sessions.

01

Hardware Assembly & Imaging

Assembled 30+ PC workstations from components, installed OS images, configured drivers, and deployed to lab stations.

02

LAN Infrastructure

Executed RJ-45 Cat6 cabling, patch panel crimping, switch configuration, and static/dynamic IP allocations across all workstations.

03

Diagnostics & Testing

Performed stress testing, bench diagnostics, and validated each workstation before going live to ensure reliability.

04

Preventive Maintenance

Established routine maintenance schedules, dust cleaning, driver updates, and performance monitoring for long-term lab health.

Configuration Snippet

DHCP configuration for lab workstation IP allocation:

dhcp-config.sh 
# Lab DHCP Range Configuration
# Subnet: 192.168.10.0/24
# Gateway: 192.168.10.1

# Static reservations for printers
dhcp-host=AA:BB:CC:DD:EE:01,192.168.10.201,printer-main
dhcp-host=AA:BB:CC:DD:EE:02,192.168.10.202,printer-secondary

# Dynamic range for workstations
dhcp-range=192.168.10.50,192.168.10.199,255.255.255.0,12h

# DNS
dhcp-option=6,8.8.8.8,8.8.4.4
